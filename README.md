路由方面，2022 年圣何塞那次测评里，电信走 163 骨干（去程经华盛顿再到圣何塞），联通经 GTT 转 AS4837 回国，移动从圣何塞直达大陆、不绕路；2025 年洛杉矶机房的测评则记录到电信 CN2 优化直连、联通经圣何塞调度、移动走 BGP 混合路由。不同机房、不同时期线路有差异，但联通线路的抖动控制在各次测试里都是三网中较好的。

要重点提醒的是晚高峰。一位四川电信 300M 家宽的站长，下午测本地下载能跑到 7-11MB/s，晚高峰只剩 130KB/s。便宜套餐走的基本是普通国际线路，出口拥挤加上这类产品普遍存在的超售，晚高峰降速是当前价格的常态——路由直达也不完全等于体验好，后续测评对圣何塞移动用户效果的评价就偏负面。买之前把预期放对位置，比事后吐槽有用。

## 下单前必看的五个限制

下面这些在条款和测评的角落里才提得到，但每一项都会实际影响使用：

1. **便宜套餐不支持退款。** 高性价比建立在大力度促销上，低价款购买后不退，下单前确认好机房和配置。
2. **别折腾 DD Windows。** 促销 Linux 套餐不允许自己 DD 安装 Windows，被发现会直接删机；确实需要 Windows 要选官方单独的 Windows 方案。
3. **没有自带备份和快照。** 面板里没有一键备份功能，用来建站就要自己养成定期备份的习惯。
4. **换 IP 收费 $3/次。** IP 被墙后可以付费切换，这个价格在业内算便宜的，但属于持续成本。
5. **按年付设计。** 官网月付款性价比明显偏低，促销福利基本集中在年付。
